## B. ★2층을 두 축으로 나눈다 — 부장님 지적이 맞았다

### 내가 뭘 틀렸나

L5(자원 회수)를 두고 *"봇 dump 로 못 보니 2층 밖으로 정리하자"* 고 했다.
**층과 자료원을 하나로 묶어서 생각한 것**이다. 둘은 직교한다.

| | 정의 |
|---|---|
| **층** | 클라 역할이 **누구냐** — 1층 단위 / 2층 봇 / 3층 실브라우저 |
| **자료원** | 판정 근거가 **어디서 오느냐** — 봇 dump / 서버 관측 |

**반증이 이미 우리 안에 있었다**: 3층 `MANUAL-LAYER-01` 의 판정 권위 ③은 브라우저가 아니라
`oxadmin` 서버 조회다(`current_rid → pause`). 20260816a 잔여 4(`oxadmin rooms` ↔ `server_config.ice`)도 같다.
**3층은 이미 서버 자료를 본다.** "서버 자료면 층이 올라간다"는 내 근거는 성립하지 않았다.

### 경계 기준 — "판정 구간이 봇 생애 안이냐 밖이냐"

부장님 표현(*"불변식으로 볼 수 있는 것 / 없는 것"*)을 기계적으로 갈리는 형태로 옮긴 것이다.

| 축 | 판정 구간 | 자료원 | 실행 단위 | 현행 |
|---|---|---|---|---|
| **정합 축** | 봇 생애 **안** | 봇 dump | `run-all` (§1-P) | 등식 46 |
| **회수 축** | 봇 생애 **밖**(run 전/후) | 서버 로그 계수 | `soak` (§1-S, N회 누적) | 등식 없음 — 사람이 읽는다 |

봇은 서버 내부를 원래 못 본다. 다만 **살아있는 동안엔 서버 반응(응답·패킷·통지)으로 내부를 추론**하고,
정합 축 46등식이 전부 그렇게 한다. L5 가 묻는 *"떠난 뒤 정리됐나"* 는 **추론할 봇이 사라진 뒤가
판정 구간**이라 원리적으로 막힌다. 도구를 잘 만들어서 되는 문제가 아니다.

### 3층 이관은 왜 답이 아닌가 (지침 4의 뒷질문)

1. **성격 불일치** — 자원 회수는 클라가 누구든 같아야 하는 성질이다. 브라우저가 판정에 아무것도 안 더한다
2. **표본 미달** — 저빈도 누적(구 생성률 0.18/run)이라 확정에 60회가 필요했다. 3층은 회당 비용이 수십 배
3. **변수 오염** — 브라우저 known flaky 가 낀다

옮기면 **관측은 되는데 표본을 못 채우는 칸**이 된다. 빈칸이 종류만 바뀐다.

### 반영

- `guide/REGRESSION_GUIDE_FOR_AI.md` **§0-I 「★축 두 개」 신설** — 위 표 + 경계 기준 + 3층 이관 기각 근거
- 같은 절에 **회수 축의 현행 한계를 명기** — 판정을 코드가 아니라 사람이 한다(`summary.txt` 육안).
  약점은 로그 문구가 바뀌면 `grep` 이 0을 돌려줘 **"값이 0"과 "물어볼 수 없었다"가 구별 안 되는 것**.
  H1 처방(`dump_integrity` 식)을 걸 수가 없다
- **L5 행** — "빈칸(2층)" → "**회수 축 소속**. 정합 축 등식 없음이 정상이지 빈칸이 아니다"
- **§5 커버리지 빈칸 → 0건**
- **§1-S** 에 "soak = 회수 축 실행 단위" 명기

|---|---|---|
| SFU 계수기 | 있음 — `DcMetrics{dc_open,dc_close,dc_association_lost}` | `metrics/sfu_metrics.rs:150` |
| SFU→hub | 있음 — 3초 flush → `ADMIN_METRICS`(0x3003) | `grpc/sfu_service.rs:224` |

| oxadmin 명령 | **없음** | `main.rs:171` 라우팅 표 |

**★그대로는 못 쓴다**: `SfuMetrics::flush()` 가 **swap(0)** — 3초마다 리셋되는 **delta counter** 다.
창을 하나만 놓쳐도 등식이 조용히 틀리고, 그건 **로그 grep 과 약점이 같다**(자료원만 바꾸고 문제는 그대로).

L5 문구(*"전부 사라진다"*)는 **사건이 아니라 상태 질문**이라 필요한 것은 **gauge**(현재 살아있는
association·peer·task 수)다. `Gauge` 원시타입은 있다(`common/telemetry/primitives.rs:45` — *"현재값,
swap 안 함"*). 즉 **gauge 신설이 실작업**이고 손대는 곳이 `oxsfud`·`oxhubd`·`oxadmin`·`oxe2epy` 4곳이다.

**gauge 가 로그보다 나은 진짜 이유**(재론 시 이 문장이 근거다): 필드가 없으면 **필드 부재**로 나와
FAIL 이 된다. 로그는 문구가 바뀌어도 **0으로 나와 초록**이 된다. "값이 0"과 "물어볼 수 없었다"가
구조적으로 구별되느냐의 차이다.

재론 조건은 §0-I 에 한 문단으로 남겼다. **설계 문서는 만들지 않는다**(미구현 설계 박제 금지).


`orchestrator` 가 SR 을 `sleep(run_secs)` **뒤**에 한 번만 보내서 SR 이후 RR 이 사실상 하나뿐이었다.

### ★저장 표본이 드러낸 것 — 등식은 원래 아무것도 검증하지 않고 있었다

### 부장님 지적이 근본이었다

> *"이거 어렵냐? 짜실짜실하게, 됬다 안됬다 그러냐? 무언가 너가 잘못 접근하고 있는거 아니냐?"*

어려운 문제가 아니었다. **순서가 거꾸로였다.**

| | |
|---|---|
| 내가 한 것 | ①덤프를 연다 → ②"SR 1개, RR 6개 있네" → ③그 위에 술어를 얹는다 → **여유가 우연히 정해진다** |
| 정석 | ①형상이 무엇을 보장해야 관측이 성립하나 → ②시나리오가 보장 → ③그 다음 술어 → ④여유 측정 |

도구(`perturb`)도 같은 방식으로 만들었다 — "이미 있는 덤프를 어떻게 흔들까"에서 출발해서
형상이 부족한 경우가 처음부터 사정거리 밖이었다.

### 수리 (`6ffe42d`)

1. **형상** — SR 을 창 **안**(`_SR_AT=0.2`)에서. 여유 14.9ms → **최소 2,498ms**, RR 1개 → 3~5개
2. **등식** — 전제를 스스로 요구(SR 이후 RR 2개 이상). 1개뿐이면 조용히 넘기지 않고 **형상 문제로
   표면화** — 서버 탓으로 안 적는다
3. **perturb** — `rtcp_send` 모드 신설. recv 만 밀면 간격이 벌어지기만 해 이 부류를 **원리적으로 못 잡는다**

## G. 한방에 — 시각 경계 부류 일괄 정리 (`29e0a3e`)

> 부장님: *"하하.. 뭐 이렇게 할게 나오냐.. 한방에 좀 끝내 보자."*

`floor_seam` 하나가 아니라 **부류 전체**를 봤다. 진행 중이던 soak 은 중단했다 —
형상을 더 고칠 거라 그때 쌓는 표본은 곧 옛 형상이 된다.

### perturb 가 네 번 틀렸다 — 전부 **낙관** 방향

| # | 틀린 것 | 실증 |
|---|---|---|
| 1 | 기준 **p95** | 여유 14.9ms 가 p95(9.87ms) 기준 "안전". 실제는 max(30.39ms)에서 뒤집혔다 |
| 2 | **격자 조밀도**(50→100ms) | `floor_seam` 실제 **67ms** 를 100ms 로 보고 → **이분**(1ms) |
| 3 | **모드 이름이 거짓** | `rtp` 가 제어 평면까지 밀어서 "미디어 대비 제어"가 **어떤 모드로도 안 변했다** → `ctrl` 분리 |
| 4 | **기준 전역 max** | 영상 시나리오 56ms 로 PTT 등식(자기 왕복 ~1ms)을 쟀다 → **표본별** 기준 |

4번은 내가 이날 넣은 것이다. 기준을 고치면서 무관한 시나리오를 섞었다.

### `floor_seam` 절벽 — 20260814 수리가 절반이었다

```
RELEASE=3.5306  GRANTED=4.0338  침묵=4.0342  새화자 첫 음성=4.0344
```

slot 은 옛/새 화자가 **같은 ssrc** 로 흐르는데 `voice_before` 를 `ts <= gr_ts`(**제어 평면** 시각)로
갈랐다. **0.6ms** 만 밀면 새 화자 음성이 옛 화자 잔류로 넘어와 −17ms → **+503.8ms** 빨강.
**503ms 는 20260814 주석에 적힌 그 숫자다** — 그때 수리는 침묵만 제외했고 절벽은 그대로였다.

→ 경계를 **미디어 자신**(`rel_ts` 이후 첫 침묵 프레임)에서 잡는다. 여유 **1.00ms → 49.06ms**.

### ★합격 기준을 바꿨다

"불안정 0" 이 아니라 **"여유가 우연이 아님"**. 정비 후 남은 뒤집힘이 전부
**50.00ms = 등식 자신의 임계**(`HANDOVER_S`·`GATING_GUARD_S`)와 일치한다 —
등식이 **자기가 선언한 예산에서만** 뒤집힌다. 어중간한 값이면 형상이 우연히 만든 것이다.
