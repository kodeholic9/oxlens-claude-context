### §4 판단 1건 — 삽입 위치 (지침 §3 보고 대상)

**①상황**: 지침 §2-3은 "`*Author: kodeholic ...*` 서명줄 **바로 위**"를 지정했다. 그러나 두 문서 말미는 **2줄 footer**였다.
```
*조사 완료: 2026-07-30. …*      ← 완료줄
*Author: kodeholic …*           ← 서명줄
```
지침이 상정한 "1줄 서명"과 실제 구조가 어긋난다(§3의 "서명줄 부재/중복"과는 다른 형태).

**②판단**: 문자 그대로 서명줄 바로 위에 넣으면 (a) `*조사 완료: 2026-07-30*`이 **2026-08-02 부록보다 위**에 놓여 시간순 역전, (b) `## 부록` 제목이 이탤릭 줄에 바로 붙어 **마크다운 파손**. → **footer 2줄 전체 위**에 삽입했다.

**③트레이드오프**: 지침 문자와 1줄 차이. 대신 지침의 실질 요구(부록=말미 / 서명줄 보존·최하단)는 **완전 충족**.

**④안전 근거**: footer 두 줄 **내용 무수정**, 상대 순서 유지, 서명줄 최하단·1회 유지(§2 검증). 되돌리기는 부록 블록 이동 1회로 끝난다. 정지점 0 지시(§3·§6-1)라 중단 없이 진행하되 본 항으로 명시 보고한다.
